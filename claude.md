# Proyecto Sherlock - Frontend Context

## Descripción General

Sherlock es una aplicación móvil gamificada donde los usuarios participan en juegos competitivos en tiempo real.

El estilo visual debe sentirse como una mezcla entre:

- PUBG Mobile
- Free Fire
- Trivia Crack
- Escape Room
- Cyberpunk ligero

La aplicación debe sentirse moderna, divertida y enfocada en videojuegos.

---

# Stack Tecnológico

Frontend:

- Angular 20
- Ionic
- TypeScript
- RxJS

Objetivo:

- Mobile First
- Android principal
- Preparado para iOS
